# Salidas científicas

Test gratuito de orientación profesional para carreras de ciencias de la vida.
20 preguntas (12 afirmaciones sobre cómo eres y 7 situaciones de trabajo científico) que devuelven
un perfil y las salidas profesionales con más afinidad.

## Archivos

| Archivo | Qué contiene | ¿Se edita a menudo? |
| --- | --- | --- |
| `data.js` | Todo el contenido: salidas, puestos, puntuaciones, preguntas, arquetipos, requisitos | Sí |
| `logic.js` | Fórmula de afinidad, filtro por carrera y arquetipo | Rara vez |
| `app.js` | Pantallas y navegación | Rara vez |
| `styles.css` | Colores y estilo | Para ajustes de diseño |
| `index.html` | Página principal | Casi nunca |

Para cambiar un texto o una puntuación basta con editar `data.js` desde la web
de GitHub (icono del lápiz) y guardar: la web se actualiza sola en un par de minutos.
